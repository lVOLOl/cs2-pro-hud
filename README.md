# CS2 Pro HUD

Оверлей для трансляций CS2 в стиле профессиональных турниров. Данные берутся из официального CS2 Game State Integration (GSI): без читов, инъекций и доступа к памяти игры.

Версия: **1.09**

---

## Что нового в 1.09

- **BLAST-вариант интерфейса** — включается в админке: вертикальные карточки игроков в ряд снизу, компактное табло, крылья бомбы/дефьюза и ROUND WIN.
- **Компактное табло** — номер раунда, овертайм, отсечки выигранных карт в BO3/BO5, «горящая» полоска стороны при стрике 5+ раундов.
- **Команды по составу** — игроки привязываются к названию команды; счёт серии и логотип сами переезжают после смены сторон.
- **Панель над миникартой** — в начале раунда карты серии (пики, победители, текущая карта), потом название турнира и стадия матча.
- **Автообсерв** (экспериментальный, **по умолчанию отключён**) — режиссёр камеры по правилам, агент для нажатия клавиш, пролётки над спавном в фризтайм.

## Возможности

### Два варианта интерфейса

Переключаются в админке: **Display Modes → Карточки игроков → Classic / BLAST**.

| | Classic | BLAST |
|---|---|---|
| Карточки игроков | горизонтальные, CT слева, T справа | вертикальные, в ряд снизу по слотам 1…0 |
| Табло | крупные блоки счёта, таймер, «X vs X» | одна компактная плашка ×1.25 |
| Бомба / дефьюз | красный таймер, кольцо прогресса, окно DEFUSING по центру | крылья по бокам табло, ничего не перекрывает экран |
| Победа в раунде | — | крыло ROUND WIN с бликом в цвет победителя |

### Табло
- Счёт CT / T, логотипы команд, таймер раунда.
- **Classic:** таймер краснеет и пульсирует при заложенной бомбе, зеленеет при дефьюзе, SVG-кольцо прогресса; счётчик живых `X vs X`.
- **BLAST:** номер раунда `ROUND 15 / 24`, в овертайме `OT1 · ROUND 27 / 30`, `WARMUP` / `HALFTIME` / `FINAL`; отсечки выигранных карт в BO3/BO5.
- **Стрик 5+ раундов подряд:** в Classic панель команды светится, в BLAST полоска стороны «горит»; стрик переносится через смену сторон.
- **BLAST-крылья:** справа — закладка (`ник / PLANTING`, заливка растёт) и `PLANTED` (заливка убывает за 40 с), слева — дефьюз (`ник / 4:086`, кит определяется сам); после раунда — `ROUND WIN`. В центре табло — прочерк при бомбе и иконка исхода (дефьюз / взрыв).

### Карточки игроков
- Аватарки Steam, HP, броня, деньги, оружие, гранаты, киллы за раунд.
- **DiR** — у мёртвого игрока вместо HP урон за раунд.
- **BLAST-карточка:** фото, плашка с HP-заливкой в градиенте стороны, K / D / деньги, оружие и гранаты, кит и бомба отдельными плашками на фото; наблюдаемый игрок выделен рамкой и приподнят.

### Наблюдаемый игрок
Два режима (админка → **Display Modes → Observed player**):
- **Detail** — аватарка или вебка, HP, оружие с анимацией патронов, броня, кит, гранаты, K / A / D.
- **Broadcast** — вебка на весь блок, плашка с именем и HP, HP-бар с «отколом» при уроне.

### Панель над миникартой
- **В фризтайм и первые 6 с раунда — карты серии:** название карты и логотип. Сыгранная — логотип победителя и итоговый счёт; текущая — зелёная подсветка и живой счёт; предстоящая — логотип команды, выбравшей карту, или `DECIDER`.
- **Дальше — название турнира и стадия матча** (админка → **Название турнира**, строки 1 и 2).
- Если задано только одно из двух — показывается то, что есть.

### Счёт серии (BO3 / BO5)
- Отсечки на табло: 2 в BO3, 3 в BO5.
- Источник: ручной счёт из админки → счёт серии из игры (`matches_won_this_series`) → сыгранные карты в вето.
- Счёт хранится **по названию команды**, поэтому сам переезжает после смены сторон.

### Команды
- Админка → **Команды**: название, логотип и состав (игроки отмечаются галочками или «Заполнить из текущей игры»).
- Сервер по составу определяет, какая команда сейчас за CT, а какая за T; логотип и счёт серии следуют за командой. Одна замена в составе не мешает.
- Без настроенных команд используются названия из игры (`mp_teamname_1/2`) и логотипы, назначенные на стороны.

### Остальное
- **Гранаты команды** — количество HE / Flash / Smoke / Molotov у живых игроков (в BLAST — над рядами карточек).
- **Статистика раунда** — в фризтайм: K / A / D, K/D, ADR.
- **Миникарта** — все соревновательные карты, два этажа Nuke, направление взгляда, номера клавиш игроков, бомба, крестики смерти, гранаты (с CSSharp-плагином).
- **Оверлеи** — TACTICAL PAUSE, окно DEFUSING (Classic), лента убийств.
- **Вебки** — SteamID64 → URL (VDO.ninja и т. п.), предзагрузка, мгновенное переключение.
- **Player Card** — отдельная карточка игрока для стримерских раскладок: `http://localhost:3000/player/1` … `/player/10`.

## Автообсерв (экспериментальный)

> По умолчанию **отключён**: в `autoobs.json` стоит `"disabled": true`. Пока он стоит, автомат не включается ни кнопкой, ни хоткеем; отладочная страница, запись GSI и прогон записей работают.

Режиссёр камеры по правилам (не нейросеть). Каждый пакет GSI сервер раскладывает ситуацию по уровням и выбирает игрока:

| Уровень | Что это |
|---|---|
| P0 | Клатч 1 против 2+ — камера на одиночке до конца раунда |
| P1 | Крупный контакт (4+ игроков) или AWP-дуэль |
| P2 | Обычный контакт: 1v1, 2v1 |
| P3 | Закладка / дефьюз при отсутствии контактов |
| P4 | Тишина — ближе всех к врагу и идёт к нему |

Контакт: враги ближе 1200 юнитов на одном этаже, и хотя бы один смотрит на другого или уже идёт стрельба. Удержание: минимум 3 с на игроке, с перестрелки не уводим, после килла держим, убили наблюдаемого — через 0.7 с на убийцу.

**Как устроено**
- Камеру переключает **агент** на ПК с CS2 — нажимает цифры 1…0 скан-кодами (консоль и `-tools` не нужны). Окно CS2 должно быть активным.
- Хоткеи в окне CS2: `Ctrl+Shift+PageUp` — включить, `Ctrl+Shift+PageDown` — выключить. Ручное переключение камеры или движение мыши ставит автомат на паузу на 5 с.
- **Пролётки в фризтайм:** спавны запоминаются по позициям игроков в первом фризтайме карты; камера облетает спавн победителя прошлого раунда (дуга / проход / кран) командой `spec_goto` через cfg-файл.

**Включить**
1. `autoobs.json`: `"disabled": false`.
2. В консоли CS2 один раз: `bind "kp_minus" "exec autoobs_frame"` (для пролёток).
3. На ПК с CS2 запустить `tools/autoobs-agent.cmd` (в нём адрес HUD-сервера).
4. Админка → **Автообсерв → Вкл**.

Подробно — [docs/autoobs.md](docs/autoobs.md): все пороги, протокол агента, запись и прогон матчей (`node tools/autoobs-replay.js recordings/<файл>.jsonl --why`).

## Установка и запуск

**Требования:** Node.js 18+ (или готовый `.exe` из релиза).

```bash
npm install
npm start
```

Сервер: `http://localhost:3000`, админка: `http://localhost:3000/admin`.

### Готовый .exe

В папке релиза лежат `cs2-pro-hud.exe` и всё, что ему нужно рядом: `hud/`, `cfg/`, `tools/`, `docs/` и JSON-файлы настроек. Запуск — двойным щелчком по `cs2-pro-hud.exe`.

Собрать самому:

```bash
npm install -g pkg
pkg server/server.js --targets node18-win-x64 --output dist/cs2-pro-hud.exe
```

Рядом с `.exe` должны лежать папки `hud/`, `cfg/`, `tools/` и файлы `settings.json`, `player-cards.json`, `veto.json`, `webcams.json`, `autoobs.json` — сервер читает их из папки, где лежит `.exe`.

## Настройка

### 1. Game State Integration

Скопировать `cfg/gamestate_integration_prohud.vdf` в

```
C:\Program Files (x86)\Steam\steamapps\common\Counter-Strike Global Offensive\game\csgo\cfg\
```

и перезапустить CS2. После обновления HUD конфиг нужно скопировать заново.

### 2. Steam API Key (аватарки)

Ключ — [steamcommunity.com/dev/apikey](https://steamcommunity.com/dev/apikey). Вставить в админке (**Steam API → Сохранить**) или в `.env` рядом с сервером:

```env
STEAM_API_KEY=ВАШ_32_СИМВОЛЬНЫЙ_КЛЮЧ
```

Без ключа HUD работает, просто без аватарок.

### 3. OBS Browser Source

| Параметр | Значение |
|---|---|
| URL | `http://localhost:3000` |
| Ширина × высота | 1920 × 1080 |
| Пользовательский CSS | `body { background: transparent !important; }` |

### 4. Перед матчем (админка)

1. **Команды** — названия, логотипы, составы («Заполнить из текущей игры» → вписать названия → «Сохранить команды»).
2. **Map Veto** — формат BO1/BO3/BO5, карты, статусы, счёт сыгранных, **Пик** (команда или десайдер) → «Опубликовать».
3. **Счёт серии** — «Авто» или вручную.
4. **Название турнира** — строки 1 и 2 для панели над миникартой и Player Card.
5. **Display Modes** — Classic / BLAST, Detail / Broadcast, гранаты на карте.

### Логотипы команд

Загрузить PNG/SVG в админке (**Team Logos**) и выбрать логотип у команды в блоке **Команды** — он будет следовать за командой. Для режима без команд — назначить логотипы на стороны CT/T или положить файл `hud/assets/teams/<Название_команды>.png`.

## CSSharp-плагин (гранаты на миникарте)

GSI не отдаёт брошенные гранаты. Плагин для CounterStrikeSharp шлёт их на HUD-сервер (`POST /grenade`).

```bash
cd csharp
dotnet build -c Release
```

`csharp/bin/Release/net8.0/GrenadeTracker.dll` → на CS2-сервер в `game/csgo/addons/counterstrikesharp/plugins/GrenadeTracker/`, затем `css_plugins_load GrenadeTracker`. В админке: **Display Modes → Гранаты на карте → Вкл**.

## Архитектура

```
CS2 ──POST /──▶ server.js
                 normalizeGSI → детект киллов → стрик → счёт серии (по командам) → логотипы сторон
                 io.emit("state") ──▶ OBS Browser Source (index.html, player-card.html)
                 autoobs.onState() ──▶ агент (Socket.IO /agent) ──▶ клавиши в CS2   [если включён]

CSSharp-плагин ──POST /grenade, /kill──▶ server.js ──▶ io.emit("grenades")

Админка ──POST /api/…──▶ запись JSON ──▶ io.emit(settings | veto | player-cards) ──▶ HUD обновляется сразу
```

## API

| Метод | Путь | Описание |
|---|---|---|
| `POST` | `/` | GSI от CS2 |
| `GET` | `/api/state` | Текущее состояние игры (отладка) |
| `GET` | `/admin` | Админка |
| `GET` | `/player/:slot` | Карточка игрока (1–10) |
| `GET` | `/api/players` | Игроки текущей игры |
| `GET/POST` | `/api/settings` | Настройки HUD (режимы, ручной счёт серии) |
| `GET/POST` | `/api/teams` | Команды: название, логотип, состав |
| `GET` | `/api/series` | Счёт серии для текущих сторон |
| `GET/POST` | `/api/veto` | Вето: карты, статусы, счёт, пики |
| `GET/POST` | `/api/player-cards` | Турнир, слоты, ELO/роли, логотипы сторон |
| `GET/POST` | `/api/webcams` | Вебки |
| `GET` | `/api/logos` · `POST /api/logo` · `DELETE /api/logo/:file` | Логотипы команд |
| `GET/POST` | `/api/steam-key` | Steam API Key |
| `POST` | `/api/streak` | Ручная установка стрика `{ side, streak }` |
| `GET` | `/api/mapinfo/:map` · `/radar/:map` | Калибровка и радар миникарты |
| `GET` | `/avatar/:steamid` | Аватарка Steam |
| `POST` | `/grenade` · `/kill` | Данные CSSharp-плагина |
| `GET` | `/api/autoobs/status` | Автообсерв: состояние, решения, журнал |
| `POST` | `/api/autoobs/config` | `{ enabled }`, `{ resume }`, `{ record }` |
| `GET/POST` | `/api/autoobs/config-file` | Содержимое `autoobs.json` |
| `GET` | `/api/autoobs/flyover/paths` | Пролётки карты (варианты, длительность, скорость) |
| `POST` | `/api/autoobs/flyover/play` · `/stop` · `/record` | Предпросмотр, стоп, запись своей пролётки |
| `GET/DELETE` | `/api/autoobs/spawns` | Выученные спавны карт |

Socket.IO: `state`, `settings`, `veto`, `player-cards`, `webcams`, `grenades`, `logos-updated`, `autoobs`, `flyover:start`, `flyover:end`; агент — пространство имён `/agent`.
