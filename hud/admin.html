Пролётки в фризтайм
Своя пролётка:
Спавны запоминаются сами в первом фризтайме карты. Пути строятся по ним (дуга, проход, кран) — или берутся из flyovers.json, если для стороны записаны свои. Точка камеры берётся из GSI (строка «Камера (GSI)» выше): лети свободной камерой и жми «+ точка» на каждом ключевом месте.

Конфиг
Приоритеты: P0 клатч → P1 крупный контакт / AWP-дуэль → P2 контакт → P3 бомба → P4 тишина. Агент на ПК с CS2: tools/autoobs-agent.cmd (в нём адрес этого сервера). Хоткеи в окне CS2: Ctrl+Shift+PageUp — включить / вернуть из паузы, Ctrl+Shift+PageDown — выключить. Ручное переключение камеры, цифры, кнопки или движение мыши в окне CS2 ставят автомат на паузу (время — timing.manual_pause_ms). Прогон записи без игры: node tools/autoobs-replay.js recordings/<файл>.jsonl --why
